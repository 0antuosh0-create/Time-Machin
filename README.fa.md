# TEMPORA — سازمان گذر زمان

> با یک کلیک، در ۱۲۵۴، ۱۹۶۵، ۳۰۰۰ پیش از میلاد یا ۳۱۲۳ میلادی قرار می‌گیرید.

«تمپورا» یک **کنسول تعاملی سفر در زمان** است که با React، TypeScript، Vite و Tailwind CSS نسخهٔ ۴ ساخته شده. این برنامه برای هر یک از **۲۴ مختصات تأییدشده** از **۳۰۰۰ پیش از میلاد تا ۳۱۲۳ میلادی**، تمام رابط کاربری را — رنگ‌ها، تایپوگرافی، فضا و تاریخ را — دوباره طراحی می‌کند و مرور تاریخ را به یک تور راهنمای تمدن بشری تبدیل می‌کند.

این یک تجربهٔ صرفاً فرانت‌اند است: تمام داده‌ها محلی‌اند، تمام صداها به‌صورت زنده ساخته می‌شوند و کل برنامه در یک فایل HTML مستقل کامپایل می‌شود.

---

## ویژگی‌های اصلی

- **۲۴ دوره، ۵ عصر** — از مصر عصر برنز تا آیندهٔ سامانهٔ دایسونی، دسته‌بندی‌شده در *باستان · قرون وسطی · رنسانس و خرد · مدرن · فراسو*.
- **صفحه‌گرد شمارهٔ زمانی** — بکشید، بچرخانید یا با کلیدهای `◄` / `►` مقصد را قفل کنید و ببینید سال روی **ماشین‌حساب رقم‌بندی** می‌چرخد (با پشتیبانی درست از پیدا/میلادی).
- **پوسته‌سازی کامل برای هر عصر** — هر ایستگاه فونت‌ها، پالت رنگی، ذرات معلق، تصویر پس‌زمینه و صفحهٔ حکاکی‌شدهٔ آرشیوی خودش را دارد.
- **صوتیات زمانیِ سنتزشده** — صدای حرکت (بازدارنده هنگام سفر به آینده، نزولی هنگام سفر به گذشته)، زنگ ورود و «ضرب» مهر گذرنامه، همگی با Web Audio API و بدون هیچ فایل صوتی.
- **گذرنامهٔ مسافر** — با بازدید از هر عصر، گذرنامه مهر می‌خورد؛ پیشرفت و مهرها در `localStorage` ذخیره می‌شوند.
- **لایه‌های روایی غوطه‌ور** — گزارش ورود، نقل‌قول‌های شنیده‌شده، دفترچهٔ راهنمای بقا («چگونه از بازدید جان سالم به در ببریم»)، رویدادهای تأییدشدهٔ همان سال، یادداشت‌های صحرایی و خط زمانی کامل وقایع‌نگارانه.
- **برخورد یادبودی** — عصرهای فاجعه‌بار (مثل برلین ۱۹۳۳) به‌عنوان رکورد آرشیوی با هشدارهای صریح نمایشی ارائه می‌شوند، **هرگز برای ستایش**.
- **دسترس‌پذیری و پرداخت** — پشتیبانی از `prefers-reduced-motion`، ناوبری با کیبورد، تصاویر متحرک کن برنز، افکت رمزگشایی متن، انیمیشن‌های مبتنی بر اسکرول و ایسترِگ پارادوکس.

## فناوری‌ها

- **React 19** + **TypeScript 5** (حالت سخت‌گیرانه)
- **Vite 7** به‌همراه `vite-plugin-singlefile` — خروجی نهایی یک فایل HTML است
- **Tailwind CSS 4** (`@tailwindcss/vite`) به‌همراه سیستم طراحی CSS سفارشی
- **Web Audio API** برای ساندِ پروسیژوال
- فونت‌های گوگل: Cinzel، EB Garamond، Marcellus، Space Grotesk، Orbitron، Syncopate و دیگران

## راه‌اندازی

```bash
npm install          # نصب وابستگی‌ها
npm run dev          # اجرای سرور توسعه
npm run build        # ساخت نسخهٔ نهایی (تک‌فایل HTML)
npm run preview      # پیش‌نمایش خروجی ساخته‌شده
```

## ساختار پروژه

```
public/images/            عکس‌های به‌کاررفته در نمایشگرهای هر عصر
src/
  main.tsx                نقطهٔ ورود React
  App.tsx                 کنسول اصلی: صفحه‌گرد، نمایشگر، ناوبری و همهٔ بخش‌ها
  index.css               Tailwind + سیستم طراحی تمپورا
  components/
    EraVisual.tsx         فید عکس یا صفحهٔ حکاکی‌شدهٔ آرشیوی برای هر عصر
    EraBackdrop.tsx       پس‌زمینهٔ تمام‌صفحهٔ اختصاصی هر عصر
    Odometer.tsx          نمایشگر رقم‌گردان سال (پ.م/م)
    Scramble.tsx          افکت رمزگشایی متن از دل نویز
    Warp.tsx              پوشش تمام‌صفحهٔ حین جابه‌جایی
    Reveal.tsx            افکت ورود با اسکرول
    scenes/index.tsx      صحنه‌های نقش‌خطی SVG عریض (currentColor)
  data/
    eras.ts               هر ۲۴ عصر + گروه‌ها، پالت‌ها، فونت‌ها، رویدادها
    quotes.ts             نقل‌قول‌های شنیده‌شده + راهنمای بقا
  lib/
    audio.ts              موتور صوتی پروسیژوال زمانی
    hooks.ts              useReducedMotion و useNow
  utils/cn.ts             کمکی clsx + tailwind-merge
```

## مدل داده

هر عصر در `src/data/eras.ts` یک بستهٔ مستقل است:

```ts
{
  id: "persia",
  year: -539, yearLabel: "539 BCE", short: "539 BC",
  name: "The King of Kings",
  group: "antiquity",
  epoch: "Achaemenid Empire · Persia",
  location: "Babylon, on the Euphrates",
  tagline: "An empire the size of a continent, run by mail.",
  description: "...",
  status: "Royal courier passing — step aside",
  fonts: { display: '"Cinzel", serif', body: '"EB Garamond", serif' },
  palette: { bg, bg2, ink, accent, accent2, muted },
  particle: { color, drift: "up" | "down" },
  danger: 1..5,
  figure?, memorial?, events[], facts[], stats[],
  image?, backdrop?, emblem, signal, confidence,
}
```

اضافه‌کردن یک ایستگاه یعنی فقط اضافه‌کردن یک آبجکت (به‌همراه یک نقل‌قول در `quotes.ts`)؛ کنسول، صفحه‌گرد، وقایع‌نگاری، شبکهٔ مقصدها و گذرنامه همگی به‌صورت خودکار آن را می‌پذیرند.

## نکات

- **بدون بک‌اند، بدون ردیابی.** همه‌چیز محلی اجرا می‌شود؛ مهرها و صدای ذخیره‌شده در `localStorage` قرار دارند.
- **عصرهای یادبودی** بدون رنگ و با شرح معتبر نمایش داده می‌شوند و نمادهای رژیم با علامت ممنوعیت سرخ پوشیده شده‌اند — رکوردی برای مطالعه، نه تأیید.
- **عصرهای آینده صادقانه تنزل می‌یابند**: ۲۰۴۹ (۸۸٪)، ۲۱۵۰ (۵۴٪)، ۳۱۲۳ (۱۲٪) — برچسب‌گذاری‌شده‌اند به‌عنوان پیش‌بینی، نه قطعیت.
